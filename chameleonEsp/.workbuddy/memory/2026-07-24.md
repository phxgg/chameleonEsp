# 2026-07-24

## vcxproj XML 结构修复
- 用户运行 build.bat 时遇到 MSB4025 错误：vcxproj 第 138 行 `<ClCompile>` 开始标记与 `</Project>` 结束标记不匹配
- 原因：上次编辑 vcxproj 添加 `/utf-8` 到 Release|x64 配置时，Edit 的 old_string 匹配并替换掉了 `</ClCompile>`、`</Link>`、`</Link>`、`<Manifest>...</Manifest>`、`</ItemDefinitionGroup>` 等闭合标签
- 修复：在 `<AdditionalOptions>/utf-8 %(AdditionalOptions)</AdditionalOptions>` 后补回所有缺失的闭合 XML 标签
- 教训：编辑 XML 文件时 old_string 不要包含过多的上下文，避免意外删除结构标签

## 中文界面乱码修复
- 用户反馈部分中文显示为乱码（骨骼→骨，诱饵→诱）
- 原因：Main.cpp 中使用 `ImFontAtlas::GetGlyphRangesChineseSimplifiedCommon()`，只包含 2500 个最常用简体字，不常用的 骼、饵 等字符不在范围内
- 修复：将中文 glyph range 改为 `GetGlyphRangesChineseFull()`，覆盖完整 CJK 统一表意文字范围（约 21000 字符）
- 文件：Main.cpp line 309
