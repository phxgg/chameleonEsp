### 构建指南

在 Visual Studio 中使用以下配置进行构建：

平台工具集：`v143 for Microsoft C++ Build Tools`

Windows SDK 版本：`Windows 10.0 SDK (最新版)`

C++ 语言标准选项：`/std:c++latest`

### 功能特性

- **透视 (ESP)**（方框、骨骼、连线、距离、名称、角色、诱饵）
- **传送**（仅在你为主机时生效）
- **角色可见性**（在感染模式中查看其他求生者）
- **防服务器踢出**
- **视野 (FOV) 修改**
- **名称修改**
- **名称窃取**
- **求生者功能：**
  - **防检测**（你的位置将不再因“埋藏过深”而暴露）
  - **无诱饵冷却**
- **猎人功能：**
  - **无枪械冷却**
  - **无限子弹**
  - **磁铁** -> 按 **G 键** 切换开关（可自定义按键）。开启后将吸附你视野前方的求生者。
  - **选择击杀目标**
  - **击杀所有求生者**
- **骨骼转储**（用于调试）

按 **INSERT** 键打开菜单，按 **END** 键卸载。
